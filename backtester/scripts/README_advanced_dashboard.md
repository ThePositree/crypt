# 🚀 Advanced Trading Strategy Dashboard

## 📋 Описание

Продвинутый дашборд для анализа результатов торговых стратегий, построенный на Streamlit. Предоставляет глубокий анализ производительности стратегии, предикторов, рыночных режимов и рисков.

## ✨ Ключевые особенности

### 🎯 **Улучшенная визуализация**
- **Градиентные карточки метрик** с цветовой индикацией
- **Интерактивные графики** с Plotly
- **Адаптивный дизайн** для разных устройств
- **Профессиональный UI/UX**

### 📊 **Детальный анализ**
- **Кривая капитала** с подграфиками доходности и просадок
- **Временной анализ** сделок по часам и дням недели
- **Анализ распределений** PnL и паттернов
- **Корреляционный анализ** предикторов

### 🔍 **Продвинутые метрики**
- **100+ технических индикаторов** из trade_analyzer
- **Анализ рыночных режимов** (бычий/медвежий/боковой)
- **VaR анализ** и управление рисками
- **Концентрация рисков** по времени и размеру позиций

### 💡 **Интеллектуальные рекомендации**
- **Автоматические рекомендации** по использованию предикторов
- **Анализ эффективности** по рыночным режимам
- **Предупреждения о рисках** и просадках

## 🚀 Запуск

### Предварительные требования
```bash
pip install streamlit plotly pandas numpy
```

### Запуск дашборда
```bash
# Из корневой папки проекта
streamlit run scripts/advanced_dashboard.py
```

### Запуск с бэктестом
```bash
# Сначала запустите бэктест с анализом условий
python -m backtester run \
  --csv data/validation/val_3m.csv \
  --symbol "SOL/USDT" \
  --strategy strategies/fvg_imbalance_v1.json \
  --capital 1000 \
  --analyze-conditions \
  --top-predictors 30 \
  --create-dashboard

# Затем запустите продвинутый дашборд
streamlit run scripts/advanced_dashboard.py
```

## 📁 Структура данных

Дашборд автоматически загружает следующие файлы из папки результатов:

- **`trades.csv`** - История всех сделок
- **`metrics.csv`** - Сводные метрики стратегии
- **`equity_curve.csv`** - Кривая капитала
- **`trade_conditions_analysis.csv`** - Анализ предикторов
- **`entry_metrics.csv`** - Детальные метрики на момент входа

## 🎨 Разделы дашборда

### 1. 📈 **Ключевые метрики**
- **Total Return** - Общая доходность с цветовой индикацией
- **Win Rate** - Процент прибыльных сделок
- **Profit Factor** - Соотношение прибыли к убыткам
- **Max Drawdown** - Максимальная просадка
- **Sharpe Ratio** - Коэффициент Шарпа
- **Average Trade** - Средняя прибыль на сделку

### 2. 📊 **Анализ кривой капитала**
- **Основной график** капитала с маркерами сделок
- **Дневные доходности** с цветовой индикацией
- **График просадок** в реальном времени
- **Статистика** по волатильности и Sharpe

### 3. 🎯 **Анализ сделок**
- **Общая статистика** по исходам и направлениям
- **Временной анализ** по часам и дням недели
- **Распределение PnL** с гистограммами и box plots
- **Паттерны сделок** и анализ серий

### 4. 🔍 **Анализ предикторов**
- **Топ предикторы** с AUC и KS статистиками
- **Корреляционная матрица** между метриками
- **Интерактивный анализ** распределений
- **Рекомендации** по использованию

### 5. 🌊 **Анализ рыночных режимов**
- **Результаты по режимам** (бычий/медвежий/боковой)
- **Эффективность стратегии** в разных условиях
- **Рекомендации** по адаптации к режимам

### 6. ⚠️ **Анализ рисков**
- **VaR анализ** на разных уровнях
- **Анализ просадок** и их длительности
- **Концентрация рисков** по времени и размеру

## 🎨 Цветовая схема

### Метрики
- 🟢 **Зеленый** - Отличные результаты (>20% доходность, >60% win rate)
- 🔵 **Синий** - Хорошие результаты (положительные, но умеренные)
- 🟡 **Желтый** - Предупреждение (близко к нулю или отрицательные)
- 🔴 **Красный** - Плохие результаты (значительные убытки)

### Сделки
- 🟢 **Зеленый** - Take Profit сделки
- 🔴 **Красный** - Stop Loss сделки
- 🟡 **Желтый** - TTL Expired сделки
