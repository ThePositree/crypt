## Context

After Product Surface Model revision 1 and the `Storybook Control Room` visual
direction were approved, the portal needed page-level contracts and wireframes
before implementation.

## Decision

Approve the current flow, screen contracts, and low-fidelity HTML wireframes
for the 11-route portal:

- `/`
- `/search`
- `/overview`
- `/architecture`
- `/data`
- `/strategies`
- `/backtesting`
- `/live-execution`
- `/operations`
- `/glossary`
- `/signal-journey`

## Consequences

The next phase is the Final Implementation Approval package. Production code
remains blocked until that package is approved or a scoped owner waiver names
the skipped gate.

## Validation Or Revisit Trigger

Revisit if implementation reveals a missing route, inadequate content depth,
search coverage issue, mobile navigation problem, or mismatch with the
approved storybook/control-room direction.
