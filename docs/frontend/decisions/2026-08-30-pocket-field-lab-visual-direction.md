# Pocket Field Lab Visual Direction

- Date: 2026-08-30
- Status: approved
- Affected artifact revisions: Design Identity revision 2; Visual References
  Interpretation revision 1

## Context

Five self-contained responsive visual direction boards explored the approved
public documentation portal. Native Codex workers produced the boards from one
shared contract, Orca browser QA verified them, and Cursor Grok 4.6 High Fast
performed an independent read-only comparison.

## Decision

Pocket Field Lab is the primary visual direction. Production design should use
its tactile field-notebook hierarchy, specimen-led chapters, dusty mint/sand/
coral palette, recurring human expedition-documentarian guide, and deliberate
mobile reading trail.

No mix or donor traits from the other four boards are approved by this
decision.

## Constraints

- Treat the HTML board as visual evidence, not production component code.
- Preserve exact technical content, accessible contrast, semantic states,
  theme support, reduced-motion behavior, and local scrolling for wide data.
- Avoid scrapbook clutter, childish styling, illegible texture, excessive
  rotation, or metaphors that hide the research/live boundary.

## Consequences

- Visual Direction Approval is complete.
- Design Identity revision 2 is approved.
- Production planning may now select the frontend stack, content architecture,
  and component system while preserving Product Surface revision 1.
- Wireframes and production implementation still require verification against
  the approved direction and product contract.

## Approval

The owner selected direction 3, Pocket Field Lab, on 2026-08-30.
