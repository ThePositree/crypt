# Visual Direction: Storybook Control Room

- Date: 2026-09-01

## Context

Five raster Visual Direction Boards were generated for the public curated
Russian documentation portal. The owner selected board 2,
`Storybook Control Room`, as the primary visual direction.

## Decision

Use `Storybook Control Room` as the primary identity for the portal. The
interface should teach the `crypt` system as a cozy cartoon control room where
subsystems are recognizable stations and multiple section-role characters help
readers move through the documentation.

Borrow selectively from the other boards:

- use `Soft Framework Manual` as a secondary reference for article density,
  right-side table of contents, and readable framework-docs structure;
- use `Animated Flow Garden` as a secondary reference for the home system map
  and signal journey clarity;
- use `Cozy Strategy Library` as a secondary reference for recipes, glossary,
  and learning-route prominence.

## Consequences

Design work should prioritize practical docs usability first: top navigation,
left tree, search, article hierarchy, glossary, recipes, and responsive states
must remain clear. The storybook layer supplies metaphors, characters,
illustrations, and warmth, but must not reduce reading density or obscure
technical explanation.

## Validation Or Revisit Trigger

Revisit if rendered wireframes or implementation show that the room metaphor
crowds article reading, harms mobile navigation, weakens contrast, or makes the
portal feel like a toy instead of a serious technical reference.
