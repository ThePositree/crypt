03 · Open manual

Logic before source code.

Pseudocode explains the invariant. A separate copyable command demonstrates a safe backtest workflow without exposing a live-money command.

decision.pseudoPSEUDOCODE
WHEN a candle closes:
  IF required data is missing:
    return NEUTRAL or BLOCK_ENTRY

  features = calculate_from_closed_candles()
  decision = shared_strategy_logic(features)

  IF mode is BACKTEST:
    replay_with_reported_assumptions(decision)
  ELSE:
    document_owner_selected_execution_path()

Quick glossary

A completed market interval whose values will no longer change.
Backtest
A historical replay under stated assumptions; not a promise of future results.
OHLCV
A compact description of price movement and volume in one candle.

Direction board notes

Kinetic Systems Workshop

Hypothesis: a connected pastel workshop can teach architecture more memorably than a conventional docs layout while preserving exact evidence and serious boundaries.

Product rationale

Visible devices turn an abstract Python pipeline into a sequential mental model for public readers.

Composition

Large orientation hero, stepwise machine track, evidence bench, open manual, then retrieval index.

Hierarchy

Oversized outcome headlines lead; numbered stations, panel titles, and compact monospace labels follow.

Typography

Rounded system sans conveys friendliness; monospace is reserved for machine labels, exact data, and code.

Density

Moderate overall; technical panels are dense locally but separated by generous chapter spacing.

Geometry

Bold outlines, offset shadows, clipped corners, belts, and modular panels—mechanical without harsh industry.

Surfaces & color

Paper and charcoal foundations with lavender, apricot, cyan, mint, and yellow semantic accents.

Iconography

Simple inline SVG devices and crypto cues; no external assets, stock imagery, or raster generation.

Motion

Restrained belt and flow movement explains direction. Reduced-motion removes animation without losing meaning.

Interactive states

Theme, search overlay, menu, copy feedback, glossary filtering, tooltip, and mascot explanation modal.

Intentionally excluded

No trading controls, live commands, account data, exchange dashboard, profit claims, GitHub dependency, or skeuomorphic controls.

Inspected targets

Designed for coordinator inspection at 1440×1000, 390×844, and 1728×1117; mobile recomposes machines vertically.

Mina’s plain-language note

Think assembly line, not autopilot.

One machine checks completed market data. One applies shared decision logic. Then the path splits: a backtest studies history, while a separately configured module may execute the owner-selected strategy on OKX. This page only explains those parts—it cannot operate them.
