01 / The big annotated map

One decision,
two bounded paths.

Both research and execution should reuse the same pure decision logic where possible. The crucial rule arrives first: indicators only see A completed market interval. The still-forming candle is excluded to prevent look-ahead..

Margin note A
Missing candle data never becomes a confident guess. It blocks an entry, produces a neutral signal, or surfaces an explicit operator error.
Margin note B
The owner may promote a strategy even when it misses a benchmark. Evidence and risk remain documented; runtime configuration remains operational truth.

03 / A glossary in the margins

Words worth
pinning down.

Short definitions help without replacing the precise chapter. Empty search recovery should always route back here.

Closed candle
A completed time interval. Using it preserves causal ordering.
Backtest
A deterministic replay of a strategy over historical market data.
Parity
Agreement between equivalent decision paths under matched inputs and boundaries.
Neutral signal
An explicit decision to take no entry when evidence is insufficient.
Production gate
A mandatory pass condition. The project benchmark is not one; it is a reporting target.
Runtime truth
Loaded configuration and exchange state that govern or record actual live behavior.

Board notes / inspection contract

Why this
direction exists.

A visual hypothesis for comparison, not a proposed component library or production implementation.

Hypothesis

An editorial sketchbook can make architecture welcoming while preserving exact technical evidence.

Product rationale

The public needs a mental model before source detail. Mira and margin notes explain boundaries without implying operational control.

Composition

Asymmetric magazine hero, oversized annotated map, alternating evidence spreads, and generous breathing room.

Hierarchy

Large serif chapter statements lead; plain-language summaries bridge to diagrams, exact specimens, then footnotes.

Typography

System Georgia supplies editorial warmth; system sans and monospace keep prose, labels, and examples robust without remote fonts.

Density

Moderate in evidence panels, deliberately low between chapters. Mobile stacks into a guided reading sequence.

Geometry

Imperfect radii, wavy underlines, dashed rules, small rotations, and graphite outlines mimic a working notebook.

Surfaces

Warm paper, taped notes, inked cards, and flat pastel fields. No glass, blur-heavy cards, or dashboard grid.

Color

Pale peach, powder blue, sage, yellow tape, and graphite. Dark mode becomes charcoal paper with muted pigments.

Iconography

Inline drawn symbols, arrows, candle marks, and a human illustrator; no external icon or image dependency.

Motion

Mira floats subtly, a data dot pulses, and loading shimmers. Reduced-motion stops all three while preserving meaning.

Intentionally excluded

Trading controls, accounts, exchange dashboard patterns, live commands, profit claims, GitHub dependency, and dark-terminal aesthetics.

Inspected targets

Designed for coordinator inspection at 1440×1000, 390×844, and 1728×1117. Mobile uses a distinct stacked composition and scroll-safe chart.

Known visual risk

System serif metrics vary by platform; the wide chart intentionally scrolls on narrow screens and needs rendered label inspection.

Direction status

Exploration only. Rendering, responsive QA, comparison, and Visual Direction Approval remain with the coordinator and owner.
