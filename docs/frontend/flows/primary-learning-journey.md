# Primary Learning Journey

- Actor and starting state: experienced Python developer and crypto trader who
  has cloned `crypt` but does not yet understand the complete system path.
- Message transition: `large unfamiliar repository` -> `coherent workbench with
  explicit data, replay, and execution boundaries`.

```text
Home
  -> Start Quick Start
  -> Verify Python/uv and install
  -> Prepare environment without live credentials
  -> Check/backfill closed-candle data
     -> missing data: show exact recovery command -> recheck
  -> Run bounded existing-strategy backtest
  -> Explain artifact types without project results
  -> Configure execution-only dry-run with fake sizing capital
     -> unsafe/missing setting: block and explain
  -> Run once
  -> Confirm no orders were sent
  -> Choose deeper Architecture / Backtester / Live Execution article
```

- Content coverage: installation, environment, data, backtest, artifact types,
  dry-run, safety boundary, and related deep documentation.
- Feedback: copied-command state, progress explanation, success boundary, and
  blocked/error recovery are visible at the step where they arise.
- Endpoint: reader completes a non-ordering dry-run and understands the next
  learning path before considering live execution.
