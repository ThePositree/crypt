# Frontend Visual Assets

Store or index visual assets required by the approved product identity here.
Every entry records a stable asset ID, immutable path, revision, content hash,
dimensions or format, source or generation provenance, usage rights when
applicable, Product Surface/content/component consumers, and review verdict.

## UI Fidelity Asset Seed

The write-scoped independent P05 Visual-System Author creates this minimal seed
only when the selected raster reference cannot be reproduced faithfully with
existing approved assets and primitives. Include the smallest representative
set needed by the production UI-library fidelity scene:
for example a licensed font decision, icon sample and rules, one illustration or
mascot treatment, one diagram vocabulary sample, or one texture treatment.

The seed is not a generic placeholder pack and is not the full site asset
inventory. A separate image-capable reviewer opens the selected board and seed,
checks their relationship, and records whether the P06 fidelity scene can use
the seed without inventing a different identity.

## Production Raster Asset Pack

P07 expands the approved direction after UI Library Approval. It may contain
actual production bitmaps, a raster collage/reference sheet for later image
generation, or both. For every region or asset record:

- direct production asset or generation reference;
- intended route, section, component, and state;
- crop and responsive behavior;
- required variants;
- forbidden text, motifs, artifacts, or substitutions;
- selected-board and UI-library fidelity relationship;
- source/licensing constraint;
- revision, hash, and independent image-review verdict.

Do not overwrite an approved seed, pack, or review input. A changed image gets a
new path or revision and requires affected re-review.
