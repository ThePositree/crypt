# Public Portal Implementation Task Contract

Status: design phase
Depth: D3
Date: 2026-08-30

## Outcome

A public, accessible, self-contained English documentation portal using the
approved Pocket Field Lab direction.

## Scope

Overview, Architecture, Research, Strategies, Execution, Concepts, History,
and Search pages; shared navigation, themes, glossary help, safe examples,
evidence presentation, and responsive reading flows.

Excluded: accounts, live data, trading controls, exchange mutations, strategy
editing, deployment controls, credentials, and live-money commands.

## Sources Of Truth

Product Surface Model revision 1, Design Identity revision 2, Pocket Field Lab
visual-direction decision, routed canonical project documentation, and active
runtime configuration only when a public production fact is later approved.

## Constraints

English content; no required external service or repository access at visit
time; exact evidence labels; closed-candle causality; accessible light/dark
themes; reduced motion; equal mobile and desktop quality.

## Acceptance Evidence

Approved wireframes and screen contracts; production tests; rendered Orca
browser QA at mobile, intermediate, desktop, and wide viewports; keyboard and
state checks; clean console/network inspection; product completeness review.

## Current Unknowns

Hosting remains unspecified. The owner selected Next.js App Router and
Tailwind CSS; static export remains the preferred deployment shape until a
server-only requirement is approved. The final recurring guide name remains a
copy decision.

## Collaboration Check

- Available: yes.
- Required interface: Orca CLI.
- Default delegated model: Cursor Grok 4.6 High Fast; native Codex workers are
  also available through Orca.
- Current phase: no new delegation. The owner previously approved agents for
  the five-board exploration, but that approval was scoped to that phase.
- Fallback: coordinator produces and reviews wireframes locally.
