# Signal Journey

## Purpose

Explain end-to-end how market data becomes a strategy decision and, when
enabled, live execution behavior.

## Primary Action

Step through the signal lifecycle.

## Information Hierarchy

1. Journey overview.
2. Step-by-step timeline.
3. State cards and contracts.
4. Backtest/live branch boundaries.
5. Recipes and failure modes.

## Messaging Contract

- Main idea: the same conceptual decision path should be understandable across
  research, backtesting, and live execution.
- Required proof: step cards, branch diagram, and related page links.
- Objections: the page shows behavior, not live trade outcomes.

## Content And Capability Contract

Coverage includes data capture, normalization, feature/indicator boundaries,
strategy evaluation, filters, risk sizing, simulation, order routing,
notifications, and feedback/reconciliation concepts.

## Interaction Inventory

Timeline step selection, branch toggle, state card expansion, related links,
recipe accordions.

## States

step selected, branch selected, partial data, blocked entry, error recovery,
dark theme.

## Acceptance Criteria

Reader can trace the signal path without needing raw source files.
