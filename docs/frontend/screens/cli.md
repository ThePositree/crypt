# CLI Reference

- Route: `/docs/cli`.
- Purpose: provide complete searchable owner-facing command and flag reference.
- Primary action: copy a supported command or open its guide.
- Hierarchy: command index; runtime/data commands; backtester run/optimize/search;
  defaults; common flags; command-specific examples; removed legacy boundary.
- Messaging: from `I need exact syntax` to `I found a supported current command`.
- Content contract: actual parser/CLI docs are the source; no undocumented command invention.
- Discovery: every command, flag, default, alias, env prefix and error suggestion.
- Interactions: command filter, anchored index, copy, option disclosures, related guides.
- States: filter results/zero, long command overflow, copy failure, deprecated/removed note.
- Responsive: option tables become labeled rows or scroll locally.
- Accessibility: filtering announces result count; tables preserve relationships.
- Related: Quick Start, Data, Backtester, Research, Configuration.
- Acceptance: supported CLI inventory is complete and representative searches rank correctly.
