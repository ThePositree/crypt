# Visual Direction Boards Review

Date: 2026-08-30
Status: ready for owner Visual Direction Approval
Scope: five standalone exploration boards; no production implementation

## Review Method

- Five native Codex workers created isolated direction boards from one shared
  product and evidence contract.
- Coordinator QA used the Orca `orca-ide` browser with target viewports of
  390 x 844, 1440 x 1000, and 1728 x 1117.
- Static HTML parsing, source inspection, browser console inspection, network
  inspection, and documentation tests supplemented visual comparison.
- Cursor Grok 4.6 High Fast performed an independent read-only source review.

## Verification Result

- All boards are self-contained English HTML with embedded CSS, JavaScript,
  and inline illustration. They make no external asset or API requests.
- All boards communicate the research workbench, closed-candle causality,
  backtest path, separate owner-selected OKX path, explicit missing-data
  behavior, and benchmark-as-reporting-target boundary.
- All boards include the required shell, search, themes, human guide,
  architecture, illustrative evidence, pseudocode, safe CLI example, content
  states, glossary, and responsive treatment.
- Mobile grid containment was corrected across all boards. At 390 x 844 no
  board has global horizontal overflow; exact charts and wide tables preserve
  readable labels through local horizontal scrolling.
- Browser console and network inspection were clean.
- Independent review identified mobile interaction blockers in directions 02
  and 05. Direction 02 now exposes a working collapsible navigation and theme
  control. Direction 05 now preserves all state/glossary specimens and has a
  functional search empty state on narrow screens.

## Direction Verdicts

1. **Daybreak Sketch Lab** — strongest match for the airy cartoon lo-fi pastel
   identity. Its annotated editorial map and margin notes teach boundaries
   clearly without resembling a dashboard.
2. **Night Shift Observatory** — the most atmospheric and compositionally
   unusual direction. It is a useful dark-mode and orbital-diagram donor, but
   its night-first mood is the least direct fit for the approved pastel lab.
3. **Pocket Field Lab** — strongest tactile documentation/archive system and
   most intentional compact reading flow. It is a strong candidate if the
   owner prefers denser, specimen-led navigation.
4. **Kinetic Systems Workshop** — strongest stepwise teaching metaphor and
   immediately legible system flow. Its bold machinery needs restraint in a
   production system so that documentation never resembles live controls.
5. **Soft Data Greenhouse** — calmest organic ecosystem metaphor and a strong
   source for rounded surfaces and pipeline illustration. Exact technical
   labels must remain dominant over the cultivation metaphor.

## Independent Ranking

Cursor Grok ranked overall identity fit as:

1. Daybreak Sketch Lab
2. Pocket Field Lab
3. Kinetic Systems Workshop
4. Soft Data Greenhouse
5. Night Shift Observatory

The recommended owner comparison is Daybreak as the identity lead, Pocket
Field Lab as the archive-density lead, and Kinetic Systems Workshop as the
teaching-metaphor lead. Greenhouse and Observatory remain valid mix donors.

## Approval Gate

The owner may select one direction, request a mix with an explicit lead, or
reject all five. Production implementation and a durable Design Identity
revision remain blocked until that choice is recorded.
